Connected requires all three: a token from a successful SMART sign-in, granted for the plan's launch profile (clinician vs patient), and at least 5 minutes left. A profile change that flips the launch profile drops the state back to Ready to sign in.
The token lives in memory only (never on disk). The tool persists client ID, launch profile, signed-in-at and expires-at so the UI can say “Expired — sign in again” after a restart instead of pretending nothing happened.
